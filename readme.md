# WebApp Express

Back-end server-side sviluppato con Node.js ed Express.js

il progetto implementa una struttura REST API con gestione delle rotte,
middleware personalizzati e organizzazione modulare del codice server-side.

---

## Obbiettivi del progetto

Questo progetto è stato sviluppato con l'obbiettivo di imparare e di approfondire:

- creazione di server backend con Express
- gestione delle richieste HTTP, testandole con POSTMAN
- organizzazione delle rotte
- utilizzo dei middleware
- sviluppo di API REST
- strutturazione modulare di un'applicazione Node


## Struttura del progetto

```text
webapp-express/
│
├── controllers/     # Logica applicativa
├── database/        # Configurazione e gestione database
├── middlewares/     # Middleware personalizzati
├── public/          # Risorse statiche
├── routes/          # Definizione delle rotte API
│
├── .env.example     # Variabili ambiente di esempio
├── package.json     # Dipendenze e script npm
└── server.js        # Entry point dell'applicazione
```

## Funzionalità

- Gestione routing Express
- Middleware personalizzati
- API REST
- Gestione richieste HTTP
- Organizzazione modulare backend

## Competenze sviluppate

Durante lo sviluppo del progetto ho approfondito:

## Installazione

Clonare il repository:

```bash
git clone https://github.com/DiegoFatVega/webapp-express.git
```

Installare le dipendenze:

```bash
npm install
```

Avviare il server:

```bash
npm run dev
```
